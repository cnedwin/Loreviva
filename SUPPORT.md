# Support

## Where to ask

| Need | Channel |
| --- | --- |
| Usage or setup question | An issue with the `question` label |
| Reproducible bug | Issue using the bug report template |
| Feature proposal | Issue using the feature request template, describing the creator or integrator problem |
| Security issue | Private report per [SECURITY.md](SECURITY.md) — never a public issue |

## What maintainers can help with

- Defects in the published snapshot, with a minimal reproduction
- Integration questions about the contract, SDK types and setup
- Review of a proposed approach before you invest in a large implementation

## What this repository does not offer

- Production support, SLAs or a hosted service
- Real model access, billing enablement or deployment help
- Recovery of data from a deleted development database

## Before opening an issue

1. Read the setup guide: [English](docs/en/04-setup-and-integration.md) /
   [中文](docs/04-setup-and-integration.md).
2. Search existing issues, including closed ones.
3. Reduce the problem to the smallest reproduction, and include the exact command,
   environment versions and output.
