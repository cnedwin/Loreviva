# Development Roadmap

Each stage defines interfaces, permissions, failure behavior and acceptance methods, then completes independent review, actual verification and paired documentation. See [support scope](00-status.md) for the distinction between design and available capabilities.

| Stage | Delivery goal |
| --- | --- |
| Tasks1–7 | Published foundation: durable core, content, memory governance, Mock Harness and Vue Studio |
| Task8 | Complete scoped sessions, SDK, reference client, thin backend and delivery recovery |
| Task9 | Portable packages, safe document import and declarative Skills |
| Task10 | Three-layer synthetic accounting, analytics and five independent industry examples |
| Task11 | Paired backup, deletion-safe restore, upgrades and maintenance |
| Task12 | Complete release, rights inventory and non-maintainer installation/workflow verification |
| Sustained characters | Stable personality, controlled growth, multidimensional relationships, memory consolidation, commitments and causal experiences |
| Creator tools | Causal authoring, comparative rehearsals, precise feedback and version migration |
| Real models and hosting | Separate validation of model quality, budget recovery, human experience, payment and deployment conditions |

Later capabilities are verified separately. Mock data, documentation and finite tests do not replace real-model, human or commercial acceptance. Customers retain final authority over identity, eligibility, player wallets and their original business services.
