# 设计与仓库支持范围

更新日期：2026年10月23日。

公开长篇设计阅读视图保留3.0.2；当前产品设计为3.1.0，R0执行基线为3.0.1。设计定义完整世界创作、角色、记忆与客户接入目标。已批准的机器契约基线仍为1.4.0（58项操作、156项Schema、迁移0001–0007）；本仓库当前代码已包含Task8开发快照，工作契约为1.6.0（67项操作、181项Schema、迁移0001–0008）。两者不可混称：工作契约入库不等于1.6.0或完整Task8已验收。契约预留项不代表实际已注册的处理器。R0 的支持面是**已验证的 Windows 本地固定卷**路径：持久性与协调层拒绝在非 Windows 卷上打开，因此单元包与维护日志只在 Windows 上执行，但代码树仍必须在 Linux 上可构建。

Task9 中唯一端到端实现的能力是 `.wepkg` 静态预检（契约1.6.0的 `preflightContentPackage` 与 `getContentPackageCapabilities`）；内容包导入、试演与本地发布尚未实现。

SDK、参考客户端与本人记忆治理的对应实现随快照入库并经过有限评审；完整Task8、1.6.0整体、Task9–12、持续角色成长与24项长期体验场景仍未作为完整产品交付。真实模型、真人体验、完整安装发行、收费和部署仍未验收。本批已知失败与未运行项见[本轮进度](../progress/2026-10-23.zh.md)，不以文档修正替代。
