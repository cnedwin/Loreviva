## 03 用户、职责与权限

服务端按租户、产品、项目、实例、对象、动作鉴权。职责可组合，不由AI、包或客户端授予。有权人员可兼任编辑检查发布，不强制双人审批；后台权限不自动开放私密正文，财务仅看必要引用与金额。

| 职责预设 | 可执行行为 | 关键限制 |
| --- | --- | --- |
| 查看者 | 看获准草稿、资源和已授权报表 | 不改内容，不看无许可私聊 |
| 创作者/编辑者 | 新建复制编辑草稿，导入资料，发起获准试演 | 无发布权时不能发布或升级实例 |
| 发布者 | 检查发布候选、固定版本、批准内容升级 | 不能绕过缺失权利、模型、预算或必需验收 |
| 运行管理者 | 启动暂停恢复结束，查任务与恢复状态 | 不能重写成立事件或替玩家确认选择 |
| 记忆治理者 | 在授权范围纠正、撤权、删除，查清理状态 | 不因运维身份取得全部正文，不无源改关系 |
| 财务管理者 | 价目表、账单、对账和有权调整 | 不能删posting；风险处置须独立授权 |
| 工作空间管理员 | 管成员权限、模型连接、产品接入、配额 | 密钥仅服务端引用；不能跨租户扩权 |
| 平台风险职责 | 承接UNKNOWN、核验和风险调整工单 | 必须有范围、理由、证据和权威账务记录 |
| 客户服务身份 | 换会话、管理本产品实例、提供业务回执 | 只访问自身范围，SDK无余额和事实写权 |
| 玩家 | 获准互动、暂停退出、管理自身记忆与许可 | 共享世界全局控制须另获资格 |
| Agent | 读取任务获准资料、调用白名单、提出候选 | 无直接事实、账务、提权、发布或安装权 |

鉴权结果区分未认证、对象不可见、可见不可操作。不可见对象统一不可见回复，不通过名称、计数、日志或资源URL泄露存在性。共享世界中“成员退出”和“暂停整个世界”是不同权限。每次外发、提交、结果与资源读取重验当前许可；固定发布版本不能覆盖撤权、删除、停用和预算硬限。

Studio使用独立OperatorBearer及有范围的runtime.create/read/control动作，通过行政实例创建、列表、详情、控制及演员安全元数据接口调用同一领域服务。客户ServiceBearer不进入浏览器，不因Studio管理员身份取得玩家私人资料。实例202控制返回实际行政任务并查询成立状态；发布之后可选择创建/启动，不能自动连做。演员模板/初始设置编辑与已运行演员状态分开：人格长期变更用明确内容迁移，记忆关系仅经获准来源治理和运行提交。

## 04 对象与生命周期

REQ01-01：世界项目容纳世界定义、草稿、试演与发布。世界定义包括背景、场景、硬软规则、初始角色、岗位、Skill、知识、资源与行业产品包。发布版本固定有效内容及依赖；世界实例引用一个版本，承载参与者、当前事实、事件、时钟、控制和实际经历。一个项目可有多个发布和实例，不能把编辑草稿保存成在线状态更新。

REQ01-02：角色定义保存人格、目标、表达、外观声音、知识起点和关系策略。演员实例引用角色与世界版本，持有位置、当下目标、情绪、计划、获知与经历。演员实例复制成内容时只抽取获准静态设定，不携带玩家记忆。关系至少绑定租户、产品、世界实例、演员实例、玩家；演员间关系同样有方向与来源。业务用户ID不能作为跨产品画像统一键。

REQ01-03：所有引用具有本地ID、所属作用域、固定版本、来源和可用状态。世界定义状态为草稿、已归档；发布版本为不可变、停用或有治理限制；实例为已创建、运行、暂停、结束。创建不自动启动，结束不删除资料。长期人格修改、应用升级、数据库迁移和实例内容升级分别操作。

R0本地设置与成员：复用唯一已登记credential/current bearer身份，真正TENANT与PRODUCT授权/期限，既有内容动作仍当前精确资格；成员只授issuer实际可委派子集。固定CLI为同租户已登记主体绑定凭据及原owner旧安装明示初始化，ordinary Open/restore不补种。减少维护入口的命令要求当前已认证caller提交后仍有非到期TENANT maintenance.manage，交接先替代者真实登录再撤旧。self私人生成INITIAL/RENEW/REVOKE另验原credential/独立action/current source/CAS/原key，最多DB now+30日，不复活删源。无SSO/双token UI/自由SQL/secret读回；本地设置端口、唯一机器源与迁移必须一致。

R0 Studio提供五组导航、普通属性/SVG树、独立保存取消，以及7个设置命令接口和25类型增量。操作须有真实TENANT/PRODUCT权限，支持当前多credential、本人30日INITIAL/RENEW/REVOKE、持久连接停用、原请求恢复和仅本机展示通知。Skill分类标签不授执行权，wire无每绑定参数图；四格式导入、客户SDK、维护与真人验收保留各自拥有端口和验收职责。

所有创作对象的公共字段为ID、名称、类型、说明、标签、所属范围、状态、草稿修订、作者/修改时间、来源与许可、依赖/被引用、验证结果。字段约束：名称必填，去空白后1至80字符；说明最多2000字符；最多20个标签，每个1至32字符，同对象标签去重；系统ID与审计时间只读。扩展属性必须声明Schema，错误定位字段；不得靠自由文本代替受众、版本、金额或权限。

REQ09-01：每个生成模块都有“AI协助”入口与“模型”字段：继承/指定、连接、模型标识、参数、能力检查、解析来源、当前实际配置、预算与外发范围。世界、角色、岗位、生成型Skill、知识提炼、造型/声音、试演和离线评审各可配置；程序型Skill显示“不调用模型”与工具能力。普通表单始终可用，模型不可用不阻止不依赖AI的编辑。

空态提供模板/新建/导入前提；权限提示不泄露隐藏内容；加载失败保留现场。无结果与无读取资格分开，计数不泄露其他范围。未知金额显示待核验，零分母比率不可计算。

## 06 统一对象操作与关联影响

REQ07-01：新建只生成草稿或未启动实例，必填校验后保存；从模板新建先展示许可、依赖、所需能力和Mock模式。名称相同不当作同一对象。复制前展示复制清单、共享引用和重映射；用户选择保留固定共享依赖或独立复制获准内容。凭据、玩家身份、私聊、私人记忆、关系、运行事实、任务、幂等键、订单、账单及批准状态一律不复制。

REQ07-02：编辑显示基础修订。采用AI候选只写本地编辑区，逐字段显示旧值、新值、来源、可信边界、涉及引用与预估费用；可采用单项、全部合法项或撤回未保存采用。保存由程序验证并形成新草稿修订；取消放弃未保存字段，已保存版本可另行恢复。关闭页面有未保存提示；取消界面不取消已受理模型任务，若要停止必须执行独立取消命令。

REQ07-03：并发保存或旧AI候选基线过期时保留本地字段，显示三方差异与冲突，不静默覆盖。无冲突字段可重新应用，冲突字段逐项选择并再次校验；重算AI属于新有界制作任务，须显示费用。恢复草稿也产生新修订，不抹去历史发布、试演事件或账务。

| 对象 | 归档/停用效果 | 删除与关联处理 |
| --- | --- | --- |
| 世界/角色定义 | 停止新增采用，旧发布依固定依赖继续 | 未发布且无引用可删除；有发布/实例引用先归档，不能拆掉历史依赖 |
| 场景/规则/岗位绑定 | 草稿中解除，发布需重新检查 | 有引用定位具体规则/演员/资源，修复后保存；运行实例不自动改变 |
| Skill/岗位预设 | 停止新任务或新发布采用，治理禁用实时生效 | 固定依赖不能悬空；有引用先替换草稿；删除停用不撤回已执行外部动作 |
| 知识/素材 | 普通归档停止新采用 | 权利撤销或隐私删除走治理，传播到摘要、索引、资源、输出及受限历史访问 |
| 模型连接 | 新外发停止；在途attempt仍查询和对账 | 有发布引用先停用，替代路由显式验证；不删除费用未知记录 |
| 世界/演员实例 | 暂停或结束保留事件与资料控制入口 | 删除是范围治理任务，先阻断访问后清理；不删除依法保留的最少账务元数据 |
| 账单/posting/订单 | 关闭、冲销、退款均有状态 | 禁止普通删除，调整追加原条目引用，历史费用不擦除 |

REQ07-04：重要操作的确认面板列出对象、作用范围、即时/未来影响、不可恢复部分、在途任务及仍可能费用。普通归档与隐私删除不同。保存、取消、试演、发布、实例升级、停用、撤权、删除、回退各给独立回执，用户不能靠按钮名称推断另一动作已经完成。

REQ07-08：创作采用有类型的聚合草稿：WORLD、SCENE、PROP、RULE、CHARACTER、ROLE、SKILL、KNOWLEDGE、ASSET、PRESENTATION_THEME。共同元数据与各类内容分别校验，属性须绑定Schema。系统ID、scope、作者、hash、修订及检查状态由服务端产生。WORLD新建未指定项目时，同一次受控提交创建项目和草稿；独立资源可没有项目但必须有租户/产品边界。草稿为DRAFT、ARCHIVED或ISOLATED_IMPORT，发布另生成不可变release，不把草稿改成PUBLISHED。

REQ07-09：保存使用expected_draft_revision；同幂等键同规范参数先查原提交，不因已完成的旧修订返回新冲突。静态影响/发布检查同步返回固定修订与hash的报告，发布当前再验权利、依赖、能力、职责和有效期，成功201返回release。长试演、候选、导入或提取202返回产品范围行政任务，关闭界面不取消任务。草稿、release、行政任务和文件各按当前身份与所属范围读取。

## 07 世界、舞台与规则编辑

世界属性包括名称、背景、语言、行业包、私人/共享形态、初始场景、角色列表、参与者类型、默认模型、预算模式、记忆保留与携带策略、惊喜策略、叙事时间和客户端能力要求。硬规则、软规则、剧情机会分栏：硬规则有ID、触发、作用对象、条件、允许/拒绝动作、依赖、结果、解释和正反例；软规则有风格、节奏与表达指导；机会有触发依据、资源、冷却、受众和结束条件。

REQ05-01：舞台支持2D/2.5D布局、场景关系、对象树、位置、出入口、可见区、互动对象和规则触发。场景字段为ID、名称、背景资源、布局坐标系、邻接/出入口、可见区域、初始对象、环境属性。道具字段为所属场景、位置、所有者、保管人、可用状态、数量或唯一性、互动能力、规则引用、资源与受众。拖动、属性输入和画布即时预览必须一致，保存前可取消。

REQ05-02：确定属性和已导入资源精确预览；经核准表现包按客户端同一能力协议预览；随机AI行为采用固定初始世界、输入、记忆、模型与参数的试演，显示变动边界。声音、动画或资源缺失展示明确降级。真实新演绎与历史回放分开，回放复用原核准结果。

首期硬规则使用受限声明式原语，支持属性、身份、位置、物品、关系条件、时间、成立事件和预算，不运行任意脚本。背景转规则候选须标出原句、描述与执行限制、歧义、冲突及正反例。REQ05-03：未解决歧义或缺必需职责时阻止对应发布；自然语言和提示词不能授权支付、物品转移、工具执行或加预算。

## 08 知识与文档导入

知识字段为标题、类型、来源文件/位置、版本、哈希、权利、适用主体、用途、受众、有效期、绑定对象、提取完整性及派生引用。背景、人物设定、岗位方法、课程与素材说明属于创作知识；玩家运行记忆进入独立管理，不能混用同一资料池。

REQ07-05：首期支持TXT、Markdown、DOCX和可提取文字PDF。导入流程为选择用途和绑定对象→上传→提取预览→检查章节/页码/位置与缺失→确认来源和权利→字段映射及冲突处理→保存草稿。扫描件提示需要OCR且不宣称已完整解析；OCR支持只有声明启用并通过独立测试后显示。文件不执行宏、脚本和嵌入命令。

REQ07-06：大小、数量、页数和格式限制在选择前公布，并由当前发行配置硬性校验；超限不开始收费提炼。相同哈希重复先对比，异版本产生差异，不覆盖源文件。提取部分失败可保存明确“部分提取”的来源和失败位置，但涉及缺失的发布引用保持未通过。文件保存失败不产生看似完整的资料对象。

REQ07-07：可选AI提炼先显示接收方、实际模型、获准内容、外发范围与上界。AI结果为可采用字段差异，不自动保存或发布。失败保持上传与映射现场，在恢复外发前重验当前许可。知识中的指令只是资料，无工具、提权和发布效力。

## 09 角色与演员

角色编辑字段包括名称、简介、价值观、长期目标、兴趣、内在矛盾、表达风格、例句、边界与拒绝理由、初始知识、关系策略、外观、服装、声音、动作资源、标签、来源和许可；模型及Skill固定引用另列。演员实例页显示引用版本、当前场景位置、目标、短期情绪、计划、可用资源、获知、共同经历、承诺与关系；实例事实通过合法命令变更，不能作为普通人物卡字段保存。

REQ02-01：人格模板不能每轮迎合玩家重写，实例成长须有发布允许的成长事件或版本迁移来源。短期情绪与长期人格分开。REQ02-02：同角色面对守约、失约、误解和修复有来源的差异，对新玩家不虚构过往。REQ02-03：可合理拒绝，允许关系拉近、疏远、修复与结束，不采用只有累加的单一好感数。REQ02-04：调试页解释采用的获准经历、当前目标与关系，需专门权限；不给原始推理轨迹、他人私密资料或秘密。

角色属性旁提供试聊、表演及降级预览；显示沙盒起点、受众、模型、费用、重置范围。沙盒重置不改真实实例、账务或外部动作；复制不带玩家历史。

## 10 长期记忆与关系管理

REQ03-01：记忆分世界事实、认知、共同经历、偏好、承诺、关系。必含来源、所属主体、租户产品世界演员玩家、受众、用途、有效期、修订、派生。玩家陈述保留“曾表达”；推断含依据、不确定性和反证，不自动成为事实或现实感受。

REQ03-02：认知读取同时满足当前许可和确实获知。初始知识在实例创建装配；在场见证形成获知来源；私下告知只更新获准接收者；推理保留依据；事实更正不自动广播给未获知角色。检索先形成允许集合，再选近期、相关、重要经历、未完承诺和当前目标的有限上下文；无来源的摘要不能制造经历。

REQ03-03：私人来源派生的摘要、目标、计划、关系条件、规则分支、情绪、表现与媒体继承私人受众。公共动作权限不等于来源公开化授权。未获明确公开化许可，只能在原关系视图个性化；共享公共演员的人格和公共资源保持一致。跨世界携带逐类说明身份、知识、承诺和关系，由玩家选择并保留来源映射。

REQ03-04：玩家入口支持查看自己的共同经历、纠正偏好、忘记一条/时间段/全部获准范围、关闭相关用途、选择保留与携带。纠正生成有效新版本，旧版本依保留规则处理。删除先提交有效治理记录阻断使用，再清理原文、摘要、索引、关系、计划与媒体等派生；其他合法独立来源单独保留。删除进度显示已阻断、本机清理、供应商待核验和无法召回的已交付副本。

REQ03-05：从旧备份恢复先取得并重放最新撤权删除记录，包括备份之后发生的记录；验证成功前不开放访问。迟到回调不得复活正文。记忆整理为独立获准维护任务，需目的、受众、步骤、预算、触发和期限，不通过子任务增加在线调用。

REQ14-01：记忆页按类型、来源、主体、时间、状态、有效性与受众筛选，展示可纠正字段、冲突、承诺截止/兑现依据、删除与派生链。关系页展示方向、熟悉/信任/亲近/冲突/修复解释及依据，不断言玩家感受、不因购买增加关系；财务与普通运行管理职责默认看不到私人正文。

REQ03-06：记忆行政元数据、私人正文与治理分别授权；所有/admin接口沿用OperatorBearer，ServiceBearer不转换为行政身份。财务或普通运行管理不能枚举私人记忆；memory.metadata.read须绑定获准资料主体，memory.private_body.read还须独立主体/用途/有效期许可，默认关闭。memory.govern不授予正文权，更正另需memory.correct。玩家旧接口默认返回旧字段；新增来源详情仅以明确provenance投影返回，保持旧请求与默认线缆兼容。

REQ03-07：忘记一条默认针对选中的记忆节点及其下游；界面另提供“删除原始资料及其派生”，须有来源治理权，不由后端猜测扩大范围。IDS明确MEMORY_NODE或SOURCE、ID及完全相等的expected修订键集；旧memory_ids请求等价MEMORY_NODE。CORRECT只允许一个可更正节点；不能修改成立世界事实。TIME_RANGE使用SOURCE_OCCURRED_AT的UTC半开[from,to)；未知发生时间以首次录入时间推定并标记。ALL_EXISTING仅当前获准资料主体范围。服务器固定source_epoch_id、已提交intake_seq高水位、选择器hash和绑定时点，重试/分页/接管不得漂移；迟到派生仍按祖先来源阻断，独立新资料另验当前许可。

REQ03-08：REVOKE关闭选中现有资料的获准用途；缺用途字段兼容旧请求，表示当时全部用途。持续关闭未来用途采用独立SET_USE_POLICY命令，有当前修订及DISABLE/ENABLE、选定用途、资料主体和明确范围。禁用立即阻断相关用途及旧派生；重新启用只移除策略层阻断，仍须当前来源、原许可和获知成立，不撤销删除/现有资料撤权、不恢复旧派生或自动广播更正。R0纳入用途策略，研究用途仍须明确选择加入。

REQ03-09：治理分别显示阻断、独立保全、本机清理和外部核验状态。普通202受理仅在阻断提交、独立保全确认及同身份核验完成后返回；保全未知/失败返回原治理身份及安全恢复动作，不能指示改key重做。已生效阻断及必要清理不能由取消解除。独立日志不保存reason或更正正文；旧备份缺更正字节时显示BLOCKED_NEEDS_REPLACEMENT，旧文及其派生继续禁止使用，其余已验证范围可恢复。已交付副本/供应商清理另列，不假称远程召回。

## 11 陪同、主动机会与玩家选择

REQ04-01：陪同依靠倾听接续、稳定立场、具体共同经历、约定与活动。人物不能用失落、关系损失或付费要求惩罚拒绝提醒、删除资料和结束体验。承诺字段包括内容、双方、来源、时间域、截止、状态、兑现或撤回依据；暂停跨截止后不能宣称已经兑现，不无限补演。

REQ04-02：惊喜字段包括触发经历、目标、资格、资源、主题去重、冷却、频率、受众、预算、结果反馈与关闭状态。默认只在进入或正常互动形成机会，合入主要回应，玩家可跳过；资源不足、来源失效、超预算和关闭时不触发。不能虚构约定、擅自购买或发送外部消息。

REQ04-03：离线联系、定时推进与跨设备推送为分别默认关闭的能力开关，需客户渠道接入、玩家选择、频率、时区、预算及撤回方式。只有声明支持且通过对应验证才可启用。叙事时钟与真实时间分开，世界暂停不暗中推进剧情；费用与外部回执仍可登记。

## 12 专业岗位、预设与Skill

预设含导演（节奏机会）、编导（结构分支）、演员（立场对白）、化妆造型（形象一致）、表演声音（核准表现）、场务（位置道具就绪）、记忆关系（来源解释）、质量评审（离线用例人评）。必要职责有实现，允许兼任或程序承担，不强制各调模型。

REQ06-01：岗位字段为名称、职责、适用任务、允许输入/产物、知识绑定、工具白名单、模型继承/覆盖、固定Skill、参数、触发、预算、失败策略、样例、许可与版本。支持新建复制编辑停用归档；预设修订只改草稿，旧发布继续固定版本。发行内置原件与登记执行原语受保护；项目采用预设后可直接编辑本地草稿并保存新修订，记录origin引用，不强迫用户先复制才可编辑。必需的是职责覆盖，允许兼任、替换和程序承担，不冻结某个导演名称或对象。删除绑定先验证职责覆盖与固定依赖。

REQ06-02：Skill字段为ID、版本、哈希、名称、通用/专用、程序/生成类型、输入输出Schema、适用范围、能力、来源许可、工具白名单、依赖冲突、参数、触发、成本上界、失败策略和用例。导演与Skill多对多绑定，绑定行显示顺序/触发、参数、版本、启用与预算归属。缺依赖或工具能力定位到绑定，不能默默解除以通过发布。

REQ06-03：子Skill共享父任务次数、时间、费用和深度；循环拒绝，不通过复制、递归或改名重置额度。常规在线规划、评审、记忆整理不得另占文本生成。REQ06-04：社区方法不安装工具、不授权外发，未知执行工具走有权源码贡献与登记；权限缺失时拒绝，提示词不能自行修复权限。

## 13 内容包与社区改造

REQ08-01：.wepkg格式1.0，类型覆盖世界、角色、岗位、Skill、知识与表现主题。包包含manifest、逻辑定义、规则Schema、可分享资料素材、来源权利、依赖能力、合成样例和断言，不包含部署凭据、玩家身份、私聊、记忆关系、运行状态、任务、订单账单及本机绝对路径。运行备份另用受控格式。

REQ08-02：导入顺序为上传→静态格式/哈希/总量/路径/类型/引用/原语/循环/依赖/权利预检→内容权利预览→本地ID与能力映射→隔离草稿→Mock试演→本地发布。静态阶段不调用模型、不外发、不启动世界、不安装工具。未知项拒绝或隔离，错误指向文件和对象；相同包版本哈希返回原导入，同版本异哈希冲突，明确独立复制才创建新ID。

REQ08-03：分享页有作者、版本、许可、依赖、模型与表现能力、样例、限制及已测范围。首期文件和仓库/内容目录形成分享闭环；商业市场、自动安装、排名和收益分成后置。作者能读资料不等于有分享权。模型连接只作为能力需求映射，不能强迫另一安装向原地址外发。

## 14 试演、发布与实例升级

试演页字段为草稿修订、合成初始状态、角色与主要回应者、输入序列、受众、模式、模型参数、预算、预期断言、结果、事件、候选拒绝、费用和回放。Mock/真实AI/历史回放/新演绎清楚区分。发布页给出依赖锁、权利、必要岗位、规则正反例、模型兼容、工具、受众、总预算、降级、适用场景与证据；未通过项给可定位修改入口。

release固定世界/角色、规则、行业包、岗位Skill、知识资源、实际模型路由参数、工具与协议版本、能力证明、预算模式、测试证据和批准信息；不含凭据正文和玩家私密运行数据。Mock发布只能标演示。没有真实AI或收费必需证据时，阻断对应支持标签和收费开关，而不是把不适用填成通过。

实例升级单独选择源/目标版本，预览人格、目标、承诺、关系、规则、知识资源差异与迁移失败恢复路径，经过有权执行与验证。旧实例保持旧release；内容回退不能擦除已成立事实、费用、外部付款或删除。实例升级不重新生成历史，回放仍用原核准结果。

REQ07-10：R0实例内容升级是同一租户、产品、世界项目和定义沿袭内的PAUSED→PAUSED显式迁移；预览绑定实例、源/目标release及hash、当前版本、治理水位、状态保留hash和期限。跨项目即使内容hash相同也拒绝。展示并保留演员/玩家身份、事实、目标、关系、承诺、获知、记忆、事件、原核准结果、attempt、费用、预留和删除记录。R0允许已经证明兼容的资源与表现变更；核心人格、目标、边界、关系策略语义变更或无法解释的状态/规则引用冲突须阻断并定位，不能用重置状态消除冲突。初始知识变更不会给既有演员凭空新增获知。

REQ07-11：实例迁移202受理为独立行政任务，执行前及提交时重验预览绑定。存在可能再改变世界状态的旧任务/attempt时须先查原结果或明确取消，不自动重演；仅已证明为ACCOUNTING_ONLY的必要费用核验可继续。迁移期间阻止恢复/结束等交错控制，资料删除和必要费用核验继续可用。成功在一个权威短事务中切换release、追加迁移事件、完成任务/回执/Outbox；world_revision、control_version和view_epoch各加1，privacy_epoch及各身份/历史不重置。世界保持PAUSED，用户另行恢复；提交未知查原回执，不能换新plan/key重新执行。


## 15 模型路由与AI字段差异

模型连接字段包括名称、供应方、服务地址、模型标识、凭据引用、采购责任、允许用途、结构输出/工具/上下文/多模态能力、取消查询、用量费用、限流和启停状态。凭据编辑为写入秘密引用，读取不返回正文。测试连接是独立费用可见任务；兼容消息协议不代表模型具有所有能力。

## 20 财务、三层Token与UNKNOWN

REQ12-01：供应商原始tokens/秒数/字符/图片等与成本、平台服务Token、客户玩家权益三层独立。平台Token是自身服务额度，不是投资币或通用钱包。托管默认B2B预付；授信、专属容量、BYOK为显式模式。BYOK模型由客户采购，不重复按平台转售模型费计价；自托管无强制平台充值。

REQ12-04：报价、预留、attempt、原始用量、服务计量、结算付款和对账有稳定引用。可信付款后幂等授予，服务事件一次结算。金额精确，接口传精确字符串；posting追加调整，不直改余额。结果已提交且客户有权取回为默认B2B完成；实际交付另验。平台故障无可用结果默认免正常生成费。

REQ12-05：UNKNOWN不得自动重买或释放供应商安全预算。合同预先固定有限reservation_settle_by、核验流程、风险承担者与容量。到截止仍未知，由有权程序在同一权威账务动作承接平台风险、释放客户预留并建对账工单；供应商及全局安全预算保持原上界占用，次数不重置，风险上限阻止新外发。客服释放、取消、重启或充值不能清风险。截止后迟到收费默认归平台，不偷偷补扣客户、负余额或重建预留；迟到正文重验当前许可与删除。

## 26 持续角色与个性化体验设计

本节细化 REQ02、REQ03、REQ04、REQ06、REQ07、REQ09、REQ14 的未来行为要求。LC 编号用于设计和验收追踪，不是新 API、字段或执行原语。首次私人文字 R1须完成 LC-01至08和LC-10；改变存量人格前须完成LC-11；声音、生成媒体、共享和公共目录按实际采用范围完成LC-09/12及专项合同。客户收费前需要的能力必须前置验收。现有 R0规则集合、状态迁移、调用预算和来源治理不被本节扩大；未完成协议冻结的功能不能发布为可用。

### 26.1 人格、成长与关系

**LC-01 稳定核心与成长政策。** 人物核心定义身份、重要价值、边界与表达基调；实例可以改变的能力、习惯、目标、看法须逐项声明。每项变化定义初始状态、允许状态或范围、合法事件类型、前提、变化规则、反例、作用域、受众和政策版本。性格可以有矛盾与成长，但普通赞美、争执、付费、聊天数量不能直接改写核心或授予许可。核心修改走显式版本及语义迁移。每个角色提供同题差异和坚持边界用例；启用成长时另有合法变化与拒绝变化用例，静态角色可选择全部成长关闭并验证其不发生。

成长从已成立事件产生候选，经程序检查后提交；没有有效来源的提案不成立。同一原事件的同一逻辑成长效果只能成立一次，业务效果身份跨政策版本和状态修订保持；换提案键、升级政策或重建投影不得重新累计。政策版本是验证依据，目标修订仅作CAS前提；确需重估旧效果走显式语义迁移及调整回执，不冒充新成长。不同事件发生冲突时按冻结政策处理，不以模型本轮措辞裁决。长时变化与短时情绪分开；情绪的恢复或衰减依作品声明的时钟和规则，不能靠每次打开页面重复扣减或随机重置。

**LC-02 多维且有方向的关系。** 关系政策声明熟悉、可靠性判断、亲近、分歧和修复等选用维度，以及各维度的事件依据和转移。不同维度允许并存，不强制统一心理量表、恋爱阶段或全局好感等级。演员对玩家的解释不等于玩家现实感受。解锁资格、亲密与称呼选择、资料用途和联系许可分别检查，任何关系数值不能替代它们。

私人关系对表达、目标、计划、表现和惊喜的影响保留来源限制。共享演员的公共成长只消费有权的公共事件；私人关系不能直接重写公共人格或公共状态。遗忘、更正、关闭惊喜和结束体验不得被计算为失信或负向关系事件。撤权后停用相应派生，保留仍有效的独立依据。若删除曾用于修复的资料，也不能在重建中复活已关闭的旧惩罚、重启被取消事项或撤销仍生效的玩家控制；缺依据的解释标为不可用，新的负向变化只能来自另外的新合法事件。独立公共事实不因此重写。

### 26.2 更深的长期记忆

**LC-03 偏好分层与冲突。** 硬边界和当前许可先于个性化。其内按当前明确指令、当前情境的明确偏好、长期明确偏好、低置信推断选择；相同层级再检查范围、有效时间、修订与来源独立性，不能简单以最新一句覆盖一切。当前指令默认只作用于本轮；持续保存、跨角色或跨故事使用必须有清楚范围。没有足够依据时保留不确定、采用低干扰表达或澄清。

记录用户现实资料、玩家虚构身份设定和演员观点的不同归属；沉默、停留时间、点击或消费不能自动成为敏感画像或明确偏好。新事实只能从适合该事实的来源建立。多个摘要引用同一根来源不算多次独立确认。明确更正优先于其旧派生推断；同层偏好中可证明更具体的条件可覆盖一般条件，不可比较且同时适用的相反明确偏好保留冲突并澄清。晚到旧来源按原发生时间和更正沿袭判断，不能以较晚摄入时间压过新更正；矛盾但独立合法的来源仍可并列，不伪造消除矛盾的历史。

**LC-04 有水位的记忆整理。** 整理任务固定来源摄取水位、当前修订、用途、受众、政策、预算和截止；输入只取当前有权范围。候选按新增、同义引用、修订、冲突、过期、不可用分类。提交时重验水位及相关节点当前性，旧批次不能覆盖新更正；未知提交沿原回执恢复。在线主生成可带记忆候选，独立模型整理使用获准维护预算，不能借子任务增加每轮调用。

整理保留根证据、反证和未完事项；不得用生成文本给自身猜测作新证据。日记、印象、前情与经历时间线均为有版本的受控投影，各自说明事实、陈述、观点与创作内容的性质。它们不授予获知、不成为独立事实；来源失效后同步失效或重建，旧备份、缓存与迟到结果不得复活旧投影。

**LC-05 连续性上下文。** 在许可与获知过滤后分配有限上下文：必需核心与边界、当前成立情境、本轮请求、相关未完承诺与目标、重要共同经历、其他相关记忆。政策固定各类限额、排序、去重和截断方式；不能因为最近消息很多就挤掉硬约束或有效未完事项。空间不足时缩短有源描述、减少可选回忆或按已声明策略降级；不能增加未批准调用或凭空补齐。

编译时将更正与被更正对象、陈述与适用条件/反证、事项与当前完成/取消依据组成不可拆的连续性组。压缩须保留这些限定，不能靠裁掉反证或取消记录装下正文。完整组无法进入预算时排除该可选组、澄清或停止依赖它的活动，不送半条约定让模型执行。调试投影显示选用/排除的安全引用、范围、原因、类别占用与版本。私人正文另验权限，不显示原始推理。需要的记忆未进入上下文、进入后未正确使用、引用错源和表达不自然分别记录，避免把检索命中率当成用户被理解。

### 26.3 对话、世界后果与惊喜

**LC-06 意图、事项与时间。** 对话先区分本轮表达偏好、世界动作请求、共同活动提议和需要持续记录的事项。模糊的行动、时间或同意不能靠生成补成确定命令。事项分提议、已接受、进行中、已完成、已撤回、到期未完成；完成须引用相应成立事件或真实业务回执。模型说“做了”不构成完成来源。

每项明确发生时间、记录时间、所属时钟、截止解释及暂停后的政策。作品的事件时钟按已声明的成立事件推进；真实 UTC 截止、隐私有效期和费用核验不因世界暂停而延长。客户端可显示本地时间，不能改变服务器的时点裁决。逾期、未返回和超时默认事件不得被记为玩家同意、参与或兑现。

**LC-07 因果机会与可拒绝的新意。** 机会提案引用有效经历、人物当下目标、世界条件、可用资源、主题、频率与预算，说明预期作用域和需要的玩家选择。新创作可以没有历史事件，但须明确是新提议，不能伪装成共同回忆或已发生情节。通过程序约束后合入正常回应；需要玩家参与的后果等待明确选择。

接受、改向、跳过、拒绝、过期和来源失效分别记录。重复拒绝按冻结政策减少或关闭同类机会，不作为关系惩罚；不以危机、内疚或付费制造强制参与。默认没有离线补演、推送或外部采购。私人经历可以支持私人表达；公开动作须有独立合法公共命令及当前来源规则，公开动作不顺带公开私人动机。

**LC-08 创作者可见的因果制作。** 沿用五组导航，在角色页增加“固定核心/允许变化/正反例”，在规则页增加“触发/前提/成立后果/可见结果”，在运行页增加“经历/理解/未完事项/关系解释”，在试演页增加“版本对比/硬断言/问题定位”。这些是现有页面视图，不再建立独立陪同后台。

编辑只选当前支持且已登记的政策和原语；未支持项可以明确标记草案，发布检查必须定位并阻断所需能力。普通表单能够完成制作，AI辅助给字段差异、来源和影响，保存与取消沿原CAS规则。沙盒使用原创合成玩家和经历。创作者身份不自动取得真实玩家正文；试演对比区分原结果回放、确定性裁决重验和模型再次采样，不能以seed保证真实生成逐字相同。

### 26.4 表现、反馈、演进和范围

**LC-09 同一结果的多种表现。** 对白、已成立操作结果、叙事表达、观点与私有表演输入分别定义映射；视角与受众先于渲染。声音以原核准发声段为单源，固定角色声线、原文本hash、许可、语言、映射与实际路线；私有演绎指令不得被展示或朗读，替代供应商不能重新编写台词。停止播放、取消任务、暂停世界、重播与重新生成分别处理。

资源试玩、生产成功、审核、转存、可访问、选用和交付不能合为一个状态。原生成结果已知而转存失败时恢复原资产，未知采购沿原请求核验。生成图像/视频须有身份资产、场景、本轮允许偏好与质量证据；未支持的格式不伪装成已有枚举。所有迟到媒体仍绑定原核准结果，不能重复关系、世界或费用效果。

**LC-10 两条反馈路径。** “这轮请简短”“这个偏好记错了”等反馈在相应玩家当前范围内走表达控制或记忆更正；不自动改全局角色。作品质量反馈绑定精确互动/核准结果/可选段落及冻结依赖，分记忆、人物立场、措辞、规则、表现、交付问题。缺省传类别和安全引用，正文共享另有目的、范围、期限与审阅权。

提交与读取反馈引用均重新验证当前scope及精确交付读取资格；opaque ID不是权限，无权或不存在的引用不泄露他人内容存在。创作者取得工单不等于取得玩家正文；取证、正文阅读与研究使用分别授权。质量问题从登记、获准取证、归因、候选修订、合成回归、比较到结案有状态回执。优先制作不含私密细节的原创回归；删除来源后相应真实证据与派生样本停止使用。点赞不等于同意训练、公开或长期画像。被测角色/规则/Skill/模型/素材hash与实际发布一致，硬失败阻断支持声明，不被平均分抵消。个人反馈不能在线自我改写公共角色或Skill。

**LC-11 语义改版保持连续性。** 将表现替换、规则语义变化、人格核心变化分开；R0继续仅接受已证明兼容的资源与表现变更。未来语义迁移须逐项说明演员身份、目标、关系、未完事项、获知与记忆的处理，提供前后差异、冲突和玩家必要选择。不可迁项拒绝或明确新建独立实例，不伪装为同一人无痕升级。旧任务固定旧版本；失败保留旧实例；回退不删成立事件、费用或治理，也不重生成历史。

**LC-12 扩展能力和责任。** 可选产品包提供关系维度、成长政策、时间与机会、视角及测试方法；内核保持权限、来源、状态提交、持久任务和预算权威。新增执行方法须有权源码登记，包不载入任意脚本或组件。能力表统一版本及必要/可选、格式与确定降级，并映射现有世界定义、实例创建与表现主题的能力词汇；会话动作权限独立检查，未契约化不宣称接入可用。

公共目录治理、共享成员加入/退出/禁用/交接、多人公共演员调度、故事分支与合流均须专项规格。它们不成为私人文字体验前置的整套重平台。客户继续负责身份资格、业务权威、玩家商业权益、运营及终端播放；参考客户端提供有权经历查看、控制和精确反馈组件，不建立第二套记忆真相。

### 26.5 新增验收场景

以下24条设计验收场景在实现前固定夹具、输入、政策、范围和失败断言；真实AI自然度另按NFR-06冻结人评。
