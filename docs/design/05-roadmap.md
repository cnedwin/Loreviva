# 开发路线

各阶段先明确接口、权限、失败行为和验收方法，完成独立评审、实际验证及中英文更新后交付。设计目标与当前可用能力见[支持范围](00-status.md)。

| 阶段 | 交付目标 |
| --- | --- |
| Task1–7 | 已公开基础：持久内核、内容、记忆治理、Mock Harness和Vue Studio |
| Task8 | 完成作用域会话、SDK、参考客户端、薄后端和交付恢复 |
| Task9 | 内容包搬迁、安全文档导入和声明式Skill |
| Task10 | 三层合成账务、分析与五行业独立样例 |
| Task11 | 配对备份、删除安全恢复、升级和维护 |
| Task12 | 完整发行、权利清单和非维护者安装及流程验证 |
| 持续角色 | 稳定人格、受控成长、多维关系、记忆整理、承诺与因果体验 |
| 创作者工具 | 因果制作、对比试演、精确反馈及版本迁移 |
| 真实模型与托管 | 独立验证模型效果、预算恢复、真人体验及收费和部署条件 |

后续能力分别验证，不以Mock、文档或局部测试替代真实模型、真人或商业验收。客户保有身份、业务资格、玩家钱包和原业务服务的最终权威。
