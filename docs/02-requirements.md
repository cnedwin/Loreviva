## 创作与关联操作

目标 GUI 应让世界、场景、规则、角色、岗位、Skill、知识与资源有一致的新建、编辑、保存、取消、复制、归档、删除和关联影响反馈。

- AI 建议先呈现差异；采纳后仍需显式保存，取消保留原已保存版本。
- 草稿可以保存不完整内容并返回精确问题；发布必须重新检查当前修订、依赖、权利和支持范围。
- 模板复制不带玩家身份、私聊、私人记忆/关系、运行事实、任务或账务。
- 发布形成固定 release；实例仍使用原版本，升级另行预览和执行。

Task7 原生 Vue 表单和 SVG 场景视图复用同一草稿及实际行政服务，已提供保存/取消、关联影响确认、可选 Mock 助手、检查和发布流程。已批准的受控自动流程不证明真人体验或所有创作目标都已验收；不支持的后续能力仍不可用。

## 世界规则与实例控制

规则需要可执行、可验证的条件和动作。编辑助手提出的内容只是候选规则，程序检查权限、资源、受众和当前状态后才提交；角色声称“已转交”不构成物品事实。当前可选助手限于 Mock，真实背景理解与规则质量仍待验收。

本批实现以下封闭控制转换：

| 操作 | 起始状态 | 成功后 |
| --- | --- | --- |
| START | CREATED | RUNNING |
| PAUSE | RUNNING | PAUSED |
| RESUME | PAUSED | RUNNING |
| END | CREATED / RUNNING / PAUSED | ENDED |

ENDED 不重新启动。原幂等键重试查询原结果，不再次增加控制版本。暂停、取消、外部请求完成和费用核验是不同状态，不能互相替代。

兼容迁移限于同租户、产品、世界项目与定义沿袭内的 PAUSED 实例。预览与执行绑定原状态及目标 release；不兼容的人格/规则改变必须阻断。已成立事件、身份、记忆、承诺、关系和费用历史不能因升级被重置。

## 来源,获知与隐私

世界事实、角色信念、玩家陈述与记忆来源分开。私人经历按实例、演员和目标主体隔离；角色要使用某来源，既需当前资格，也需实际获知记录。

行政记忆元数据查询、私人正文读取、治理和用途政策是不同权限。后台能看任务或元数据不授予私人正文和模型使用权。纠正/删除应先阻断使用，再由持久任务清理；状态如实展示，不能把“已受理”写成“全部删除完成”。

## 模型,岗位与 Skill 的目标要求

每个生成模块应有模型继承/指定、能力检查、实际解析来源、预算与外发范围。程序型岗位/Skill 不成为文本生成者；适用的 `NONE` 关闭生成，不静默回退到其他模型。

岗位与 Skill 支持版本化绑定、输入输出 Schema、能力/工具白名单、许可、依赖、参数、触发和失败策略。缺依赖定位到绑定，不能默默删去配置。方法不得自行授权工具、递归重置额度或额外购买模型调用。

Task7 已实现对应 Mock 路径的原生编辑 GUI；真实供应商执行仍属后续任务。本批固定内容/路由并检查在线 Skill 资格；`NONE` 终止生成，当前许可与实际获知必须同时成立，父任务调用上限和共享额外槽均由程序守住。当前只支持 Mock 路径，不向真实供应商外发资料。

## 接入,恢复与计量的目标要求

完整 Integration Kit 应覆盖客户后端身份核验、受限会话、快照、互动、原任务查询、事件/媒体续取、控制、记忆治理与业务回执。现有 TypeScript 包保留生成类型和配置封装，并新增有限行政 HTTP 客户端 `createAdminClient`，支持行政契约调用、鉴权资产读取与上传；它不是完整客户 SDK，不提供玩家会话/互动/SSE 接入或客户身份适配器。

任务结果、服务完成、供应商费用和风险预留需要分别展示。`UNKNOWN` 表示原结果待确认，不等于失败、零费用或可自动重新采购；成功接收请求也不等于世界动作成立。Task6已在合成Mock范围验证原attempt查询恢复、必要成本、迟到费用与服务结果分离；UNKNOWN继续查询原身份，不自动重新购买。候选属于原草稿及来源许可作用域，采纳后仍需显式保存；排练创建隔离的临时世界、保留FAIL/NOT_RUN及清理进度。行政元数据可见不等于私人结果正文可读。Task7 已有本地设置界面；上述工程证据不等于计量管理页面、客户玩家流程或真实商业收费已完成。

客户保留玩家身份、业务资格、行业目标和玩家支付/退款权威。未来平台服务额度与玩家钱包独立，平台服务退款不自动触发玩家退款。
