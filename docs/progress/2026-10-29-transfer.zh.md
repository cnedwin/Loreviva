# 内容包审核、导出与安装迁移

创作者可以把有权分享的已发布静态内容导出为 `.wepkg`，在另一套安装中重新匹配模型、能力和素材，导入为隔离草稿，再完成审核与发布。原安装的不可变版本保持不变。

## 创作流程

1. 在“内容与资源”选择已发布内容，填写包标识、版本及公开作者名，核对所有定义和素材的复制、再分发许可，生成并下载内容包。
2. 在目标安装读取原包，明确选择本地模型、已登记能力、来源用途和素材受众。包内素材可提取后经正常上传成为 READY 资产，再显式匹配；导入不会自动安装文件或工具。
3. 保存为隔离草稿并检查当前修订。世界需要原始输入非空、结果全部成立且适用断言完整通过的真实本地 Mock 试演。未适用的保管规则不会阻断审核，已适用但未运行的规则不能当作通过。
4. 填写审核说明并批准当前保存修订。审核新增一个内容相同的修订，保留受保护的来源记录。发布前再做当前修订检查，明确创建不可变版本。编辑、复制、历史恢复或有效模型路由改变后，旧审核不能继续授权发布；需要保存隔离修订并重新审核。

## 接口与存储

| 操作 | 接口 |
| --- | --- |
| 批准隔离修订 | `POST /world/v1/admin/content-drafts/{draft_id}/isolation-approvals` |
| 生成静态包 | `POST /world/v1/admin/content-packages/exports` |
| 读取导出回执 | `GET /world/v1/admin/content-packages/exports/{export_id}` |
| 下载原始内容包 | `GET /world/v1/admin/content-packages/exports/{export_id}/archive` |
| 提取原包声明素材 | `POST /world/v1/admin/content-packages/file-bytes` |

所有接口使用当前操作员身份；产品查询和请求体以唯一机器契约为准。写操作保存原始请求标识与输入；未知结果用相同请求恢复，不创建新键重复操作。下载验证大小与 SHA-256；素材响应元数据与实际文件绑定，不授予本地用途。

导出只遍历定义规范声明的引用位置及精确可达依赖，不改叙述文本。每项纳入内容与素材须允许复制和再分发；跨主体私有编辑内容、过期许可、私有来源地址和带查询或片段的来源 URL 不进入导出。自由文本仍须创作者核对，自动校验不代表语义隐私审查。模型保留能力要求及可表示参数，不携带本地连接、模型身份、预算或凭据。已有 PROGRAM Skill 的登记能力可映射，任意代码、工具安装与完整 Skill 社区工作流仍不在本范围。

迁移 `0010` 增加 `content_package_adoptions` 和 `content_package_exports`；迁移 1–9 原始字节保持不变。审核证据、来源与文件证明在最终事务内复核，文件锁持续至审核返回。导出 ZIP 与回执在同一命令事务提交；每次下载重查当前来源、权限和资产。已交付字节不承诺远程召回。备份恢复必须纳入这两张表及其关联记录，完整恢复验收留在后续运维工作。
