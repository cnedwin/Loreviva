# Loreviva

**The AI Platform for Living Worlds**  
创造世界，让它持续生长。

## 本地检查

需要Go 1.27.2、MySQL Community LTS、Node.js 24、pnpm 11.25.0。
R0当前支持已验证的Windows本地固定卷；Linux构建检查不等于Linux运行支持。
完整启动、迁移与凭据配置见搭建指南；应用没有默认管理员密码。

先安装冻结依赖，检查生成契约并构建Go应用。运行pnpm test:integration-runner可在不连接数据库的情况下验证分片运行器。
数据库集成测试另需受限测试账户和可销毁数据库，每个测试创建自己的数据库。运行node scripts/run-integration-shards.mjs --shards 4可执行分片测试；共享服务器负载和计时仍会影响结果，不承诺固定加速比例。

运行器核对进程退出、包级结果与每个计划目标终态，输出使用新目录，保存独立stdout/stderr日志和summary.json。退出**0**表示初跑具备完整通过/跳过证据，跳过项仍须检查；**1**表示失败或证据不完整；**2**表示初跑失败仅在串行重试后通过，需要复核，不能记成干净通过。重试失败、缺结果或跳过不会清除原失败。
